# Como aplicar este overlay

Este patch foi gerado especificamente sobre `ZIMTV-IPTV-PS4-LIVETV2-TEST-SOURCE.zip`. Extraia o ZIP original e, em seguida, extraia o conteúdo deste overlay na raiz da mesma pasta, permitindo substituir os arquivos. Não apague arquivos existentes.

O overlay contém apenas os arquivos modificados e o relatório. Ele não inclui executáveis, dados de teste temporários, bibliotecas proprietárias do SDK ou um PKG PS4. Os testes host e as limitações do build estão descritos em `docs/relatorio-correcao-host.md`.
